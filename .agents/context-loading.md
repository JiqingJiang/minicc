# 上下文加载规则

1. 读根目录的 [AGENTS.md](../AGENTS.md)、[项目目标](../docs/project-goal.md)和当前范围的局部规则。向用户说清本轮目标及其与最终目标的关系。
2. 从[流程入口](skills/README.md)选择当前阶段。按模块查[模块文档](../docs/modules/README.md)，核对现有运行方式、实现和验收条件。
3. 按功能名、接口或用户原话查 [Agent Notes](notes/README.md)。先查 `proposed/` 和 `implemented/`，需要了解历史方案时查 `rejected/` 和 `archived/`。
4. 接手时确认当前阶段、已有授权的范围、实际改动、用户体验反馈和各轮验证结果。使用最近一次明确授权继续对应范围。授权或状态无法确认时，在会话中核对。已有版本证据时，带上提交号或测试快照标识。
