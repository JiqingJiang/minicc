# Agent Notes 目录约束

本目录遵循 `README.md` 定义的生命周期、分类、文件格式和迁移规则。

- 重要变更在同一个 PR 中新增或更新 Note。
- Note 必须放入 `{lifecycle}/{class}/`，不得创建未登记的分类目录。
- 文件头的 `# Agent Note:` 和 `Status:` 保持规范格式；正文使用中文。
- 每份 Note 必须记录真实考虑过的替代方案及其落选原因。
- `implemented/` 描述当前已交付事实；`proposed/` 描述尚未交付的方案。
- `rejected/` 和 `archived/` 中的 Note 冻结，不作为当前实现依据。
- 变更决策时创建新 Note 并建立相对链接，不把旧 Note 改写成相反决策。
