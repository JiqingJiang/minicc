# Agent Notes

这里存放用户明确指定、需要跨会话复用的讨论依据和决策理由。日常问答、方向认可、常规改动和进度汇报留在会话里。现行约定归对应规则，模块行为和验证证据归[模块文档](../../docs/architecture.md#模块文档)。

## 何时写

只有用户明确要求记录或维护某项 Note 时，才在这个范围内新建、更新或迁移。讨论、写 spec、实现和验收各走自己的流程。需要保存的内容已有合适入口时，优先维护原文并引用它。

## 怎么写

先找同主题记录，使用[模板](_template.md)保留未来会话真正需要知道的背景、决定、理由和证据。只有相关时补充备选方案、未决问题或重议条件。路径用 `<状态>/<类别>/YYYY-MM-DD-主题.md`。

| 状态 | 含义 |
| --- | --- |
| `proposed/` | 仍在讨论，或已确认但待实现或验证。 |
| `implemented/` | 已落地且经过验证。 |
| `archived/` | 暂存、过时或已被替代。 |
| `rejected/` | 已明确放弃。 |
