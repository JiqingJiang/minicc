# Agent Note · 把协作规则与决策放进 MiniCC

状态：implemented

## 问题

MiniCC 刚开始。用户希望采用 DeepSeek Harness 的协作方法，使不同 Agent 和新会话都能查到项目约定、曾经考虑过的选项和验收依据。

## 决策

使用 [AGENTS.md](../../../../AGENTS.md) 作为共用入口，`CLAUDE.md` 链接到同一份规则。按任务读取[开发与评审流程](../../../skills/README.md)，长期取舍随变更写入 [Agent Notes](../../README.md)，按状态和主题查找。

## 备选与取舍

只在聊天里保留讨论最省事，但跨会话时需要人补述背景。把所有理由放进根规则便于一次读取，但会让每个任务重复加载无关决定。采用按需读取的 Markdown，并保留否决记录，代价是改动涉及旧决策时要同步更新事实和链接。

## 影响

规则和决策可以随项目复制。当前采用中文和人工核验。团队需要多语言或发现格式检查反复出错时，再评估自动化。

## 验证

从 [项目入口](../../../../README.md) 检查规则、流程、模板与示例之间的相对链接。检查 `CLAUDE.md` 指向根规则，并检查四个状态目录均已建立。
