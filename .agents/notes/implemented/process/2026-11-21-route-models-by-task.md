# Agent Note · 按任务分配 Sol 和 Luna

状态：implemented

## 问题

用户希望复杂判断和重要任务由能力较强的模型负责，由 Luna 执行边界清楚的动手任务。多人同时改动、交接时遗漏约束以及误判实际模型都会影响结果。

## 决策

按[模型分工](../../../skills/model-routing.md)推进。重要任务优先由 GPT-6.2-Sol 主导，Luna 承接已明确范围和验收方式的实现。由主 Agent 核对实际改动并完成整体验收。

## 备选与取舍

单模型执行可省掉交接，小任务尤其适用。重要任务拆给多个 Agent 能让主会话集中处理取舍，但每次派工都有上下文和复核成本。实施范围高度耦合时，顺序推进可以避免并行改同一处。

## 影响

分工由共用规则入口触发。具体可选模型由当前客户端和会话提供。模型或委派能力不可用时，交付说明记录实际做法。

## 验证

本次使用 Codex 的 Luna 执行角色编写模型分工流程。核对规则入口到流程及其引用的本地链接，并核对 Claude Code 的共用规则链接。
