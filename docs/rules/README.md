# 项目规则

这里维护跨任务持续生效的 MiniCC 约束，按主题拆分，避免把所有细则堆进根目录 `AGENTS.md`。Codex 会自动读取仓库根目录的 `AGENTS.md`；该文件要求每项任务先读本索引，再按任务主题读取对应规则。

| 规则主题 | 规则文件 | 何时读取 |
| --- | --- | --- |
| 文档归属与整理 | [documentation.md](documentation.md) | 创建或修改项目文档、spec、模块说明和决策记录时 |
| Git 提交格式 | [git.md](git.md) | 创建提交时 |

规则记录持续有效的行为约束。`docs/decisions/` 记录具体决策为何这样选，以及未来什么条件下需要重议；不要把规则复制成决策记录。
